# Test Case Design

Target: https://www.saucedemo.com/  
Test type: UI functional testing  
Automation: Playwright Test + JavaScript  
Environment: Chromium, desktop

| ID | Scenario | Test data | Expected result | Automated |
|---|---|---|---|---|
| TC_LOGIN_001 | Login with valid credentials | standard_user / secret_sauce | Products page is displayed | Yes |
| TC_LOGIN_002 | Login with invalid password | standard_user / wrong_password | Authentication error is displayed | Yes |
| TC_LOGIN_003 | Login with empty username | Empty username / secret_sauce | Username-required error is displayed | Yes |
| TC_LOGIN_004 | Login with empty password | standard_user / empty password | Password-required error is displayed | Yes |
| TC_INV_001 | Verify inventory page | Valid user | Six inventory items are displayed | Yes |
| TC_INV_002 | Add a product to cart | Valid user | Cart badge shows 1 | Yes |
| TC_INV_003 | Sort products by price ascending | Valid user | Prices are in ascending order | Yes |

## Execution notes

- These are designed test cases; actual pass/fail results must be generated by running the suite.
- The public demo site and its content can change. Re-check locators and expected behavior if a test fails.
- Use only the site's documented/demo credentials; never use personal credentials.
